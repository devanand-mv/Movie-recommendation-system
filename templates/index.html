Content-Based Filtering

How it works:

Content-based filtering recommends items based on a comparison between the content of the items and a user profile. In this application, we model the "content" of a movie using its genres.

1
TF-IDF Vectorization We clean and vectorize pipe-separated genres using Term Frequency-Inverse Document Frequency (TF-IDF). This scores the importance of each genre relative to the entire movie catalog.
2
Cosine Similarity We compute the angle between the TF-IDF vectors of all movies: \[\text{Similarity}(A, B) = \frac{A \cdot B}{\|A\| \|B\|}\] A similarity score of 1.0 represents identical genre categories.
👥

Collaborative Filtering

How it works:

Collaborative filtering makes recommendations based on the preferences and ratings of other similar users. This application implements **Item-Item Collaborative Filtering**.

1
User-Item Rating Matrix We compile user ratings into a large table where rows are movies and columns are users. Unrated cells are set to zero.
2
K-Nearest Neighbors (k-NN) Using Scikit-Learn's `NearestNeighbors` classifier with Cosine Distance, we search for movies whose historical user rating distributions are geometrically closest to the selected movie.
